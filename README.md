# IMDb Movies Data Analysis

## Overview

This project performs Exploratory Data Analysis (EDA) on the IMDb Movies India dataset to explore movie ratings, votes, directors, actors, and overall trends in Indian cinema.

The analysis uses Python's data science ecosystem to clean, process, visualize, and interpret movie-related data through statistical analysis and graphical representations.

---

## Objectives

* Understand the structure and quality of the IMDb Movies dataset.
* Perform data cleaning and preprocessing.
* Analyze the distribution of movie ratings.
* Identify the most frequently appearing directors and actors.
* Explore the relationship between movie ratings and votes.
* Generate visual insights using charts and graphs.

---

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

---

## Key Insights

* Analysis of the distribution of IMDb movie ratings.
* Identification of the top 10 directors based on the number of movies.
* Identification of the top 10 actors based on their appearances.
* Analysis of the relationship between movie ratings and audience votes.
* Visualization of correlations between numerical movie attributes.
* Data cleaning and preprocessing to improve the quality of the analysis.
